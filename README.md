# FUTURE_DS_03
Customer Behavior Analysis
📌 Project Overview
The objective of this project is to analyze customer purchasing patterns, understand customer preferences, identify key business trends, and create an interactive dashboard that helps businesses make data-driven decisions.The project covers the complete Data Analyst workflow, starting from data exploration and cleaning to SQL analysis and dashboard development.

🎯 Business Problem
This project focuses on answering important business questions such as:

What is the average customer purchase amount?
Which product categories generate the highest revenue?
What percentage of customers are subscribed?
Which age groups contribute the most sales?
Which categories perform better in terms of sales and revenue?
What insights can improve customer engagement and retention?

🔄 Project Workflow
Understand the business requirements.
Explore and understand the dataset.
Perform data cleaning and preprocessing using Python.
Conduct Exploratory Data Analysis (EDA).
Load and analyze data using PostgreSQL.
Write SQL queries to answer business questions.
Create an interactive Power BI dashboard.
Generate business insights and recommendations.
